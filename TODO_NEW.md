## Category A: Complete Missing API Endpoints

These are full API resources described in the TFE docs with zero implementation in Terrence.

### A.1 Workspace Resources API

- **Reference:** `references/docs/enterprise/api-docs/workspace-resources.mdx`
- [ ] `GET /workspaces/:workspace_id/resources` — List resources tracked by the workspace's current state
  - Return type: `type: "resources"` with attributes: `address`, `name`, `created-at`, `updated-at`, `module`, `provider`, `provider-type`, `modified-by-state-version-id`, `name-index`
  - Permissions: read access to workspace
  - Pagination support required

### A.2 Workspace Transfers API

- **Reference:** `references/docs/enterprise/api-docs/workspace-transfers.mdx`
- [ ] `POST /workspace-transfers` — Queue a workspace transfer between organizations
- [ ] `GET /workspace-transfers` — List all transfers
- [ ] `GET /workspace-transfers/:transfer_id` — Show transfer status
- [ ] `POST /workspace-transfers/:transfer_id/actions/cancel` — Cancel transfer
- [ ] `POST /workspace-transfers/:transfer_id/actions/resume` — Resume paused transfer
  - Transfer attributes: `approval-mode`, `cleanup-on-failure`, `history-cutoff`, `policy-set-mode`, `variable-mode`, `workspace-prefix`, `workspace-suffix`, `status`, `pause-reason`
  - Relationships: `source-workspace`, `destination-organization`, `destination-project`, `events`
  - Requires user token, owner or admin in both orgs

### A.3 Plan Exports API

- **Reference:** `references/docs/enterprise/api-docs/plan-exports.mdx`
- [ ] `POST /plan-exports` — Create a plan export (async, generates Sentinel mock bundle)
- [ ] `GET /plan-exports/:id` — Show export status
- [ ] `GET /plan-exports/:id/download` — Download exported data (tar.gz, temporary URL, redirect)
  - `data-type`: currently only `sentinel-mock-bundle-v0`
  - Status: `queued` → `finished` / `errored`, expires after 1 hour
  - Found via `relationships.exports` on plan objects

### A.5 Queries API

- **Reference:** `references/docs/enterprise/api-docs/queries/index.mdx`
- [ ] `POST /queries` — Create a query run against a workspace
- [ ] `GET /workspaces/:workspace_id/queries` — List query runs
- [ ] `GET /queries/:query_id` — Show query run
- [ ] `POST /queries/:query_id/actions/cancel` — Cancel query
  - Query attributes: `source`, `variables`, `status`, `log-read-url`, `status-timestamps`
  - Relationships: `workspace`, `configuration-version`, `created-by`, `canceled-by`
  - Separate from regular runs — query runs inspect resources without modifying state

### A.6 Public SCIM API (Provisioning Endpoints)

- **Reference:** `references/docs/enterprise/api-docs/scim/` (index.mdx, groups.mdx, users.mdx)
- Note: Admin SCIM settings/tokens API **is** implemented. The public SCIM provisioning endpoints under `/scim/v2/` are **not**.
- [ ] `GET /scim/v2/ServiceProviderConfig` — SCIM service provider capabilities
- [ ] `GET /scim/v2/Schemas` — Supported SCIM schemas
- [ ] `GET /scim/v2/ResourceTypes` — Resource type metadata
- [ ] `GET /scim/v2/ResourceTypes/User` — User resource type metadata
- [ ] `GET /scim/v2/ResourceTypes/Group` — Group resource type metadata
- [ ] `GET /scim/v2/Users` — List SCIM users (with filters: `userName eq`, `externalId eq`)
- [ ] `POST /scim/v2/Users` — Create SCIM user
- [ ] `GET /scim/v2/Users/:id` — Show SCIM user
- [ ] `PUT /scim/v2/Users/:id` — Update SCIM user
- [ ] `PATCH /scim/v2/Users/:id` — Partial update SCIM user
- [ ] `DELETE /scim/v2/Users/:id` — Deprovision SCIM user
- [ ] `GET /scim/v2/Groups` — List SCIM groups (with filters: `displayName eq`, `externalId eq`)
- [ ] `POST /scim/v2/Groups` — Create SCIM group
- [ ] `GET /scim/v2/Groups/:id` — Show SCIM group
- [ ] `PUT /scim/v2/Groups/:id` — Update SCIM group
- [ ] `PATCH /scim/v2/Groups/:id` — Partial update SCIM group
- [ ] `DELETE /scim/v2/Groups/:id` — Delete SCIM group

### A.7 Policy Evaluations API

- **Reference:** `references/docs/enterprise/api-docs/policy-evaluations.mdx`
- [ ] `GET /task-stages/:task_stage_id/policy-evaluations` — List policy evaluations in a task stage
- [ ] `GET /policy-evaluations/:id/policy-set-outcomes` — List policy set outcomes for an evaluation
  - Policy evaluations are distinct from policy checks (run in agents, part of task stages)
  - Attributes: `status`, `policy-kind` (sentinel|opa), `policy-tool-version`, `result-count`, `status-timestamps`
  - Filtering on outcomes: `filter[n][status]`, `filter[n][enforcementLevel]`

### A.8 Explorer API

- **Reference:** `references/docs/enterprise/api-docs/explorer.mdx`
- [ ] `GET /organizations/:org/explorer` — Query workspace data across org (read-only)
  - View types: `workspaces`, `tf_versions`, `providers`, `modules`
  - Rich field selection per view type
  - Complex filtering syntax: `filter[INDEX][FIELD][OPERATOR][0]`
  - `sort`, `fields`, pagination support
  - 60-second timeout
- Note: TODO.md references Explorer only for the `bulk-actions` change-request endpoint, not the main query API

### A.9 Nodes API

- **Reference:** `references/docs/enterprise/api-docs/nodes.mdx`
- [ ] `GET /api/v1/nodes` — List all node IDs (container ID, pod name, allocation ID, or hostname)
  - Used by diagnostics endpoint for node-targeted checks
  - TFE-specific system API endpoint
